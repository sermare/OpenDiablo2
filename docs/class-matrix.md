## How to run

```
OD2_VERIFY_NIGHTLY=1 scripts/verify_classes.sh                  # all seven classes, five scenarios each, one game at a time
OD2_VERIFY_NIGHTLY=1 scripts/verify_classes.sh --classes necro,amazon --resume
scripts/verify_classes.sh --dry-run                             # what would run
scripts/verify_classes.sh --render                              # regenerate this file from the results table
```

Plan and time: 7 classes x 5 scenarios, about 35 to 45 minutes per class with the sped-up game clock (x3 to x4) of the scenarios and one game window,
so 4 to 5 hours for the whole matrix; the table and the per-run logs are kept in `$OD2_CLASS_MATRIX_DIR` (default
`/tmp/od2-class-matrix`: `results.tsv`, `<class>.<scenario>.out`, `<class>.<scenario>.log.txt`). `--resume` continues an
interrupted night. The anomaly column is the first `FAIL:` line of verify.sh, else the first error, warning, give-up or
dropped-skill line of the game log.
